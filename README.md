# PascalIS Library

PascalIS is a set of intelligent systems library, mainly for gaming. It mostly implements classic intelligent system algorithms.

As of now, there's only one unit `VSComputerGameAI` that provides abstract classes for two player zero sum games
and one example using that unit for Tic Tac Toe game.

This is a hobby project stemming long ago from my intelligent systems class back in college. Improvements in terms
of pull requests are welcome. Words are fine, but code is a hell lot better.
